# Aerospace-Design-And-Physics-Toolkit-Solver (ADAPTS)
Just a passion project where I just apply what I learnt in 5 years in IITB

Since one of my seniors and juniors are making their own solvers, why should I be left out.

About the Repo:
Make a unified tool for aircraft design for multiple archetypes, along with first order and second order relevant physics.


Primary function:
i) Preliminary design
ii) Feasibility Check


Secondary function:
i) Potential Failure Warning System

Had this in my mind for literal years, finally came around to actually building it.
